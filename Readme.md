## `parse_code.py`

This file provides utilities for parsing Python code using the `ast` (Abstract Syntax Tree) module. It can analyze single files or entire directories to extract information about classes, functions, and their docstrings.

### Classes

#### `CodeAnalyzer`
A custom `ast.NodeVisitor` subclass designed to traverse a Python Abstract Syntax Tree and extract specific information such as imports, class definitions, function definitions, and their respective docstrings.

**Methods:**

##### `__init__(self)`
Initializes the `CodeAnalyzer` instance. It sets up internal data structures (lists) to store the extracted information, such as imports, class definitions, and function definitions found during the AST traversal.

**Parameters:**
- `self`: The instance of the `CodeAnalyzer` class.

**Usage Example:**
```python
from parse_code import CodeAnalyzer
import ast

code = "import os\ndef my_func(): pass"
tree = ast.parse(code)
analyzer = CodeAnalyzer()
analyzer.visit(tree)
# analyzer.imports, analyzer.classes, analyzer.functions will now contain data
```

### Functions

#### `parse_single_file(file_path)`
Parses an individual Python file content string or path. This function takes either the content of a Python file as a string or a `pathlib.Path` object pointing to a file, and returns a structured dictionary containing information about its imports, classes, and functions extracted using the `CodeAnalyzer`.

**Parameters:**
- `file_path`: A string containing the Python code or a `pathlib.Path` object to the Python file.

**Usage Example:**
```python
from parse_code import parse_single_file
from pathlib import Path
import tempfile

# Example 1: Parsing from a string
code_content = """
import math

class MyClass:
    \"\"\"A sample class.\"\"\"
    def my_method(self, x):
        \"\"\"A sample method.\"\"\"
        return x * x

def greet(name):
    \"\"\"Greets the given name.\"\"\"
    return f"Hello, {name}!"
"""
parsed_data_from_string = parse_single_file(code_content)
print(parsed_data_from_string["functions"][0]["name"]) # Output: greet

# Example 2: Parsing from a file
with tempfile.NamedTemporaryFile(mode="w", suffix=".py", delete=False) as f:
    f.write(code_content)
    file_path = Path(f.name)

parsed_data_from_file = parse_single_file(file_path)
print(parsed_data_from_file["classes"][0]["name"]) # Output: MyClass

file_path.unlink() # Clean up the temporary file
```

#### `parse_code_directory(dir_path)`
Recursively walks through a folder and parses all nested `.py` files. This function takes a `pathlib.Path` object representing a directory and processes every Python file found within it and its subdirectories. It returns a dictionary where keys are file paths and values are the parsed data for each file.

**Parameters:**
- `dir_path`: A `pathlib.Path` object to the directory to be parsed.

**Usage Example:**
```python
from parse_code import parse_code_directory
from pathlib import Path
import tempfile
import os

# Create a temporary directory structure for demonstration
temp_dir = Path(tempfile.mkdtemp())
(temp_dir / "my_module.py").write_text("def func_in_module(): pass")
(temp_dir / "sub_dir").mkdir()
(temp_dir / "sub_dir" / "another_file.py").write_text("class MyClass: pass")
(temp_dir / "not_a_python_file.txt").write_text("just text")

parsed_directory_data = parse_code_directory(temp_dir)

for file_path, data in parsed_directory_data.items():
    print(f"File: {file_path.name}")
    if data["functions"]:
        print(f"  Function: {data['functions'][0]['name']}")
    if data["classes"]:
        print(f"  Class: {data['classes'][0]['name']}")

# Clean up the temporary directory
import shutil
shutil.rmtree(temp_dir)
```
